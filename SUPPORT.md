# Support

nvault is an alpha OSS project. Community support is best effort.

After the repository is public, use GitHub Discussions for usage questions and
GitHub Issues for reproducible defects. Do not put credentials, private keys,
passphrases, tokens, customer data, or sensitive logs in either place.

Use the private process in [SECURITY.md](SECURITY.md) for a suspected security
vulnerability.

The managed nvault Cloud service has a separate support and security boundary.
