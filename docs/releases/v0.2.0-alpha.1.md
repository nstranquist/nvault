The protected `v*` tag ruleset blocks creation, update, and deletion except for
repository administrators. The `main` branch requires the Linux, macOS,
Windows, race-detector, static/security, and TypeScript package checks. This tag
is annotated but is not cryptographically signed. Release immutability was not
enabled before this first release, so the recorded digests remain the
authoritative check for its assets. Future workflows also create GitHub artifact
attestations before publication.

## External consumer verification

A clean module cache installed the public tag with:

```sh
go install github.com/nstranquist/nvault/cmd/nvault@v0.2.0-alpha.1
nvault version
```

The installed binary reported `nvault 0.2.0-alpha.1`. The remote annotated tag
resolved to the recorded commit.

`@nvault/client` is not published on npm. The package owner must first reserve
the package and configure npm trusted publishing for `npm-publish.yml` and the
`npm-release` environment. No customer, payment, download adoption, or revenue
claim follows from this release.
