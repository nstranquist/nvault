# Maintainers

The repository owner is the sole maintainer before the first public release.
The first public release must name the active maintainer in the repository
settings and release receipt.

Maintainers review security-sensitive changes, wire compatibility, release
artifacts, and dependency updates. Two-person review is recommended for a
cryptographic or identity-format change when another qualified reviewer is
available. An automated test result is not a professional cryptographic audit.

Governance can expand after outside contributors and users exist. Changes to
governance must be recorded in this file and the changelog.
